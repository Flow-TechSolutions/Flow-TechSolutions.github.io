# Accessibility

Flow-TechSolutions is committed to making its website accessible and usable for as many people as possible, including people with disabilities.

## Our Approach

We aim to design and maintain this website in accordance with established web accessibility best practices and, where reasonably possible, the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA.

Accessibility is considered when developing and updating:

- Navigation and page structure
- Keyboard interaction
- Color contrast
- Form controls and labels
- Responsive layouts
- Focus indicators
- Semantic HTML
- Screen reader compatibility
- Reduced-motion preferences

## Supported Environments

The website is designed to work with current versions of major modern browsers, including:

- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari

The website is also designed to support desktop, tablet, and mobile devices.

## Known Limitations

While we aim to provide an accessible experience, some parts of the website may not yet be fully optimized for every assistive technology or individual accessibility requirement.

We continuously review the website and may improve accessibility as the service develops.

## Reporting an Accessibility Issue

If you experience an accessibility barrier while using this website, please contact us.

Email:

hotelmanagementflow@gmail.com

Please include, where possible:

- The page where the issue occurred
- A description of the problem
- The browser and device you were using
- Any assistive technology you were using
- A screenshot or additional information, if helpful

We will review accessibility reports and make reasonable efforts to address identified issues.

## Feedback

Accessibility feedback is welcome and helps us improve the experience for all users.
